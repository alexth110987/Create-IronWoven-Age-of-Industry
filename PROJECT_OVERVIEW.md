# Project overview

## What is Create IronWoven?

Create IronWoven: Age of Industry is an industrial and steampunk Minecraft modpack built around Create and Create Aeronautics.

The aim is to create a world where mechanical engineering, production lines, trains, transport, automation, exploration, and large-scale building work together.

**Build. Engineer. Explore. Transport. Automate.**

## Project focus

- **Engineering:** machinery, mechanical systems, and practical factory design.
- **Automation:** build connected production systems rather than relying only on manual crafting.
- **Transport:** trains, vehicles, logistics, and movement of goods.
- **Exploration:** discover the world and find useful places and resources.
- **Building:** create industrial, steampunk, and functional structures.

## Technical target

| Component | Target |
|---|---|
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.265 |
| Java | 21 |
| Mod distribution source | CurseForge |

Windows is the current development and test environment. Linux server support is planned, but has not yet been tested.

## No backports

**NO BACKPORTS.** The pack targets its selected Minecraft version. The project will not maintain older Minecraft branches or downgrade mod versions to support an older game version.

## Project status
