**Status: Public Beta available through CurseForge.**

## Official download

The official [Create IronWoven: Age of Industry CurseForge page](https://www.curseforge.com/minecraft/modpacks/create-ironwoven-age-of-industry) lists the client modpack and a separate dedicated-server pack, both named **v0.1.124.5 Beta** and published on **25 November 2026**. CurseForge is the only approved distribution source.

Install the client through the CurseForge application using the project page. For a dedicated server, select the matching **Server Pack** file from the project's Files section; do not substitute the client profile or mix versions.

The current generated repository development version is v0.2.124.5, but the file verified on CurseForge in this check is v0.1.124.5 Beta. Always follow the exact file/version currently listed on CurseForge.

## Planned game requirements

| Component | Target |
|---|---|
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.265 |
| Java | 21 |
| Mod source | CurseForge only |

The exact requirements will be confirmed again on the release page when the pack is published.

## Install the client Beta

1. Install and open the CurseForge application.
2. Find [Create IronWoven: Age of Industry](https://www.curseforge.com/minecraft/modpacks/create-ironwoven-age-of-industry).
3. Install the listed **v0.1.124.5 Beta** client file.
4. Launch from the installed CurseForge profile.
5. Check the version displayed in the profile before joining a server.

For server installation, use the matching v0.1.124.5 Beta Server Pack file from the official CurseForge project page. Server setup, compatibility and feature validation remain Beta-stage; do not assume every feature is complete.

Do not manually mix mod files from different pack versions. Client and server files must match the published release instructions.

## Server information

Windows is the current development/test environment. Linux server support is planned but has not yet been tested. Do not treat planned Linux support as a verified compatibility claim.
