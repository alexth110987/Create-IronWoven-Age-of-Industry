**Status: Development in progress.**

## Is the pack available to download?

Not yet. There is currently no downloadable public release of Create IronWoven: Age of Industry.

This page will be updated with the official CurseForge download link and step-by-step installation instructions when a public release is approved. Please do not use old test folders, private development files, or unofficial mirrors as a substitute for a release.

## Planned game requirements

| Component | Target |
|---|---|
| Minecraft | 1.21.1 |
| Mod loader | NeoForge 21.1.265 |
| Java | 21 |
| Mod source | CurseForge only |

The exact requirements will be confirmed again on the release page when the pack is published.

## When a release is available

The installation guide will cover:

1. Installing the supported CurseForge launcher.
2. Opening the official Create IronWoven profile.
3. Allowing the launcher to install the required files.
4. Starting the game and checking the installed pack version.
5. Joining a supported multiplayer server, when one is available.

Do not manually mix mod files from different pack versions. Client and server files must match the published release instructions.

## Server information

Windows is the current development/test environment. Linux server support is planned but has not yet been tested. Do not treat planned Linux support as a verified compatibility claim.
