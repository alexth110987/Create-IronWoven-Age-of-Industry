# CurseForge Beta downloads are available

The official Create IronWoven: Age of Industry CurseForge page currently lists the client modpack and matching dedicated-server pack as **v0.1.124.5 Beta**, published 25 November 2026.

Download and install from the [official CurseForge project page](https://www.curseforge.com/minecraft/modpacks/create-ironwoven-age-of-industry), and use the version shown on the selected file page. This is a Beta: feature and compatibility validation is still ongoing, and file availability does not mean every feature is complete.

The private development version shown in project records is not necessarily the uploaded CurseForge file version. The CurseForge file page is the source for the download you install.
