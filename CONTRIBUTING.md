# Player feedback and contributions

Thank you for your interest in Create IronWoven: Age of Industry.

## How to help

The most useful help is clear, respectful player feedback:
- Report problems that can be reproduced.
- Explain what you expected and what happened instead.
- Include the exact pack build when one is available.
- Suggest improvements that fit the engineering, automation, transport, exploration, and steampunk direction.

## Where to send feedback

- **General player problems and suggestions:** use the [main public issue tracker](https://github.com/alexth110987/Create-IronWoven-Age-of-Industry/issues).
- **Beta access applications:** use the [beta application form](https://github.com/alexth110987/Create-IronWoven-Age-of-Industry/issues/new?template=beta_application.yml). Applications are reviewed privately; submission does not grant access automatically.
- **A specific beta functional-test action:** use the [Functional Test Result form in the Beta hub](https://github.com/Create-IronWoven/Create-IronWoven-Age-of-Industry-Beta/issues/new?template=functional-test-report.yml). Submit one action per report and select Single-player, Multiplayer, or Both.

Do not use the general player issue tracker to submit a functional-test checklist result. Use the Beta hub for beta-specific testing; it is separate from ordinary player support.

## Please do not upload

- Third-party mod JAR files.
- Full world saves or private backups.
- Passwords, access tokens, private server details, or personal information.
- Full unfiltered logs when a short relevant excerpt is enough.

## About suggestions

Suggestions are welcome, but they are not automatic commitments. Every proposed mod or change must be checked against the project's Minecraft and NeoForge target, dependencies, server/client requirements, and overall compatibility.

**NO BACKPORTS:** contributions must not introduce support for older Minecraft versions or legacy branches.
