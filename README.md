# Create IronWoven: Age of Industry

![Create IronWoven: Age of Industry](assets/Ironwoven_%20Age%20of%20Industry.v2.png)

**Build. Engineer. Explore. Transport. Automate.**

Create IronWoven: Age of Industry is an industrial and steampunk Minecraft modpack built around **Create** and **Create Aeronautics**. The project focuses on engineering, automation, trains, transport, exploration, and large-scale building.

> **NO BACKPORTS**
>
> Create IronWoven targets its selected Minecraft version. The project does not maintain or support backports to older Minecraft versions, legacy branches, or downgraded mod versions just to support an older game release.

## Where to go for feedback

**Beta access is restricted.** You need an invitation or an approved application. [Choose beta tester application](https://github.com/alexth110987/Create-IronWoven-Age-of-Industry/issues/new/choose), then select **Beta tester application**. Applications are reviewed manually; submitting one does not automatically grant access.


- **General player problems:** use the [main public issue tracker](https://github.com/alexth110987/Create-IronWoven-Age-of-Industry/issues).
- **Beta test reports:** use the separate [beta-tester repository](https://github.com/Create-IronWoven/Create-IronWoven-Age-of-Industry-Beta). Its functional-test form is for recording a specific test action, not ordinary player support.
- **Community chat:** the Discord invite will be added here once the public invite is ready.
- **Project development:** internal research and development remain in the private repository and are not part of this public player hub.

Before opening an issue, please check [Known issues](KNOWN_ISSUES.md) and [Support](SUPPORT.md). Include the exact pack build you are using when one is available. Remove personal information, private IP addresses, local usernames, passwords, and tokens from logs or screenshots.
