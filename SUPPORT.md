## Is a public pack available?

Not yet. There is no downloadable public release. Please wait for the official release instructions rather than installing old test files or combining mods from different sources.

## Before opening a support issue

When a public release is available:

1. Check that you are using the exact Minecraft, NeoForge, and pack versions listed for that release.
2. Make sure your client and server use matching pack versions.
3. Restart once and check whether the problem happens again.
4. Read [Known issues](KNOWN_ISSUES.md).
5. Search the [main issue tracker](https://github.com/alexth110987/Create-IronWoven-Age-of-Industry/issues).

## What to include

Please provide:
- Exact pack version or release name.
- Minecraft and NeoForge versions.
- Whether the issue occurs in single-player, on a dedicated server, or when joining a server.
- What you were doing before the problem happened.
- Clear steps to reproduce it.
- Relevant error text or a short log excerpt, when useful.

## Protect your privacy

Before attaching logs or screenshots, remove:
- Usernames and personal information.
- Private server addresses and IP addresses.
- Local file paths that identify you.
- Passwords, access tokens, and other secrets.

Do not upload full world saves, private backups, account data, or third-party mod JAR files.
